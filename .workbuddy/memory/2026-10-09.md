# 2026-10-09

## Yangine：多光源阴影（PCSS + CSM + CubeShadowMap）

把原有的「单方向光 + 单张 2048 shadow map + 一次比较采样」升级为完整的多光源阴影体系。

### 数据模型
- 新建 `src/Lights.ts`：`DirectionalLight` / `PointLight` / `SpotLight` 统一接口，
  `assignSlots()` 为每盏灯分配连续的阴影矩阵槽位（CSM 级联 / 立方体 6 面 / 聚光 1 张），
  并区分「矩阵槽」与「本地阴影数组层」（`matBase` vs `localBase`）。
- 每个光源 128 字节（8×vec4）打包进 storage buffer；阴影矩阵单独一个 storage buffer。

### 阴影贴图布局
- `csmArray`：2048² × 4 层，depth32float，供平行光级联使用。
- `localShadowArray`：1024² × 12 层，供点光源立方体（6 面）与聚光灯（各 1 层）使用。
- 分开存放是因为两类贴图分辨率不同，无法放进同一个 array texture。

### PCSS（`Lighting.wgsl`）
三阶段：blocker search（12 采样，Vogel 盘）→ 半影估计 → PCF（24 采样）。
- 搜索半径与过滤半径**解耦**，因此半影宽度是物理正确的，而非固定大小的糊边。
- 正交（CSM）与透视（点/聚光）走不同的半影公式；深度先经 `linearizeDepth` 线性化。
- 采样旋转角由 `hash12(fragCoord + 帧号)` 生成，噪声交给 TAA 摊平。
- 逐槽位递增 `baseBias` 抑制自阴影摩尔纹（级联间、立方体相邻面间）。

### CSM
- `splitCascadeDistances()`：practical split scheme（λ=0.7），对数与均匀分布混合。
- 每级用视锥切片的**包围球**做正交投影，包围球法比 AABB 更小且旋转不变。
- **texel snapping**：把包围球中心投到光空间后按 texel 网格对齐，消除相机移动时的阴影爬行。
- 级联边界做双级联 smoothstep 混合，消除硬切换接缝。

### 踩坑记录（重要）
1. **`OrbitCamera.forward()` 原实现有 bug**：写成 `normalize(target + (-eye))`，
   仅当 target 为原点时等于 `target - eye`。本项目 target 是 `[0,1,0]`，导致相机前向算错。
   CSM 级联选择完全依赖这个向量，必须用 `vec3Sub(target, eye())`。已修复。
2. **WGSL 静态检查盲区**：`tsc` 完全不看 WGSL。用 Dawn(wgpu-py) 编译才抓到两个真实错误：
   - 删变量时漏改引用：`fragCoord` 已删除但光照循环里仍在用。
   - 类型不匹配：`let lightCount = i32(...)` 却写 `i = i + 1u`（i32 + u32）。
3. **`wgpu.utils` 不能 import**：它会初始化画布后端，在无显示环境下**静默终止进程**
   （无异常、无输出、exit 0），排查时极具迷惑性。只 import `wgpu` 本体。
4. **无头浏览器拿不到 GPUAdapter**：本机 Edge headless 下 `requestAdapter()` 返回 null，
   即使加 `--use-webgpu-adapter=swiftshader` 也无效。改用 wgpu-py 走原生 Dawn 后端。
5. **NDC 与 UV 别混淆**：投影矩阵输出 NDC 中心是 `(0,0)`，经
   `uv = ndc*0.5+0.5` / `v = 0.5-0.5*ndc.y` 才是 uv `(0.5,0.5)`。写断言时踩过两次。
6. **立方体面中心不能作为投影测试点**：它与 lookAt 的 eye 重合，视线深度为 0 → w=0 → NaN。
   应测光源自身位置（在视锥轴上）。

### 立方体阴影朝向约定
`CUBE_FACE_UPS` 传入 `mat4LookAt` 时**取负**，使渲染到 2D array 后的纹理 v 轴
（向下）与立方体映射约定对齐，采样端无需再翻转。面顺序
`+X,-X,+Y,-Y,+Z,-Z` 与着色器 `dirToCubeUV` 的 face 索引严格对应。

### 新增校验工具（`tools/`）
- `validate_wgsl.py` — Dawn 编译全部 7 个着色器，捕获语法/类型/绑定声明错误。
- `validate_pipelines.py` — 真实创建渲染管线，校验绑定组布局与采样器类型匹配。
  （着色器编译通过 ≠ 管线能创建成功）
- `verify_lights.mjs` — 51 项数值断言：深度映射、linearizeDepth 可逆性、
  级联分界单调性、立方体六面朝向、槽位分配无重叠。需先 esbuild 打包
  （因为 `Lights.ts` 用无扩展名导入，Node 无法直接解析）。
- 已接入 `npm run verify`，一条命令跑完四层：typecheck → wgsl → pipelines → lights。
